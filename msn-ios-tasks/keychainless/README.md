# Описание

## KeyChainless

**Платформа:** iOS
**Категория:** MASVS-STORAGE
**Сложность:** Medium

Наш разработчик реализовал хранение токена авторизации и пароля пользователя
локально между запусками, чтобы не логинить пользователя каждый раз, но
допустил косяки с безопасностью — вам нужно их исправить.

При анализе незашифрованной резервной копии устройства (iTunes/Finder backup)
эти значения нашлись в открытом виде в одном из системных plist-файлов
приложения — без взлома, без root/jailbreak, достаточно доступа к бэкапу.

Исправление должно перенести секреты в защищённое хранилище, которое не
попадает в незашифрованные бэкапы.

## Файл для исправления

- `CredentialStore.swift`
