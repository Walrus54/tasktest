# Описание

## ECBinary

**Платформа:** iOS
**Категория:** MASVS-CRYPTO
**Сложность:** Medium / Hard

Наш разработчик реализовал шифрование пользовательских данных перед отправкой
на сервер, но допустил косяки с безопасностью — вам нужно их исправить.

При аудите заметили, что при шифровании одного и того же значения несколько
раз подряд получается одинаковый шифртекст, а при шифровании данных с
повторяющейся структурой (например, изображения или записи фиксированного
формата) в шифртексте видны те же повторяющиеся блоки, что и в исходных
данных — классический признак режима без IV/nonce. Вдобавок ключ шифрования
извлекается напрямую из строковой константы в коде, то есть его можно достать
из бинарника.

Исправление должно закрыть обе проблемы: и режим шифрования, и способ
получения ключа.
