# Описание

## WorldReadable

**Платформа:** Android
**Категория:** MASVS-STORAGE
**Сложность:** Easy

Наш разработчик реализовал сохранение токена авторизации локально, чтобы не
просить пользователя логиниться каждый раз, но допустил косяки с
безопасностью — вам нужно их исправить.

При аудите обнаружили, что стороннее приложение, установленное на том же
устройстве (без root и без специальных прав), может прочитать этот токен
напрямую из файла на диске — причём значение читается в виде обычной строки,
без какого-либо шифрования.

Исправление должно закрыть обе стороны проблемы: файл хранилища не должен быть
доступен другим приложениям, а сам токен не должен лежать в открытом виде даже
для того, кто получит доступ к файлу другим способом (например, через backup).
