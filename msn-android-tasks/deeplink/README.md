# Описание

## DeepLink

**Платформа:** Android
**Категория:** MASVS-PLATFORM
**Сложность:** Medium

Наш разработчик реализовал открытие экрана сброса пароля по ссылке из письма
(`https://mobsec.app/reset-password?token=...`) через App Links, но допустил
косяки с безопасностью — вам нужно их исправить.

При клике по такой ссылке система показывает диалог выбора приложения, хотя
ссылка ведёт на настоящий домен `mobsec.app`: любое стороннее приложение может
объявить тот же intent-filter и перехватить ссылку вместе с токеном сброса.
Вдобавок экран сброса пароля открывается по любым ссылкам домена, а не только
по `/reset-password`.
